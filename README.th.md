# Jarvis Calls You 📞 (ภาษาไทย)

**AI ที่โทรหาคุณจริงๆ** ผ่านสายโทร Telegram ใช้เสียงสดของ Gemini Live คุยได้ทันที ค้นเว็บได้ มองเห็นกล้องได้ จดโน้ตให้ และโทรกลับมาทีหลังได้

## ใช้ทำอะไรได้
- ⏰ โทรปลุก และโทรเช็กงานตามเวลาที่ตั้งไว้
- 🚨 สั่งให้โทรหาเมื่อมีเหตุการณ์ เช่น เว็บล่ม ระบบพัง ประตูเปิด ส่งคำสั่ง curl ครั้งเดียว มือถือก็ดังทันที
- 🚗 โทรหา AI ตอนขับรถ ถามอะไรก็ตอบเป็นเสียง
- 📷 เปิดกล้องหรือแชร์จอในสาย แล้วให้ AI ดูได้
- 📝 วางสายแล้วจะได้ข้อความสรุปกับโน้ตทาง Telegram
- 🔌 เพิ่มเครื่องมือของตัวเองได้ แค่วางไฟล์ Python ไว้ในโฟลเดอร์ tools/

## ติดตั้ง
1. มี Python 3.10 ขึ้นไป, บัญชี Telegram สำรองสำหรับ AI, คีย์ Gemini ฟรี และ API ID ของ Telegram ฟรีจาก my.telegram.org
2. ดับเบิลคลิก `install.bat` (บน Mac หรือ Linux ใช้ `./install.sh`)
3. เปิดไฟล์ `.env` ใส่คีย์ แล้วตั้ง `LANGUAGE=th` กับ `OWNER=@ชื่อผู้ใช้ของคุณ`
4. `python -m callme login` ล็อกอินบัญชี AI ครั้งเดียว
5. ดับเบิลคลิก `run.bat` ให้ทำงานตลอด

## สั่งทางแชท
พิมพ์หาบัญชี AI ได้แบบนี้: `โทรหา` / `โทรมาอีก 20 นาที เรื่อง ปิดเตา` / `โทร 06:30 เรื่อง ปลุก` / `สถานะ` / `ยกเลิก`

## ความปลอดภัย
- ใช้บัญชี Telegram สำรองเท่านั้น
- AI รับคำสั่งจากเจ้าของ (OWNER) คนเดียว
- ไฟล์ data/ai_account.session คือกุญแจบัญชี ห้ามแชร์ให้ใคร

## สายเดโมให้คนทั่วไปโทรหา (ไม่บังคับ)
ตั้ง `PUBLIC_MODE=on` ในบัญชี Telegram **แยกต่างหาก** ใครก็โทรมาคุยกับ AI ได้ แต่
- จำกัดสายละ 3 นาที คนละ 2 สายต่อวัน และรวมไม่เกิน 40 สายต่อวัน
- ไม่มีเครื่องมืออะไรเลย นอกจากจดข้อความฝาก และห้ามบอก prompt คีย์ หรือข้อมูลส่วนตัวของเจ้าของ
- ทุกสายจะส่งสรุปให้เจ้าของทาง Telegram พร้อมชื่อคนโทรกับข้อความที่ฝากไว้

## แก้ปัญหา
- รัน `python -m callme check` เพื่อดูว่าขาดอะไร
- สายติดแต่ AI ไม่พูดเลย แล้ววางสายเอง: คีย์ Gemini โควต้าหมดหรือคีย์ผิด หลังวางสาย บัญชี AI จะส่งข้อความบอกสาเหตุมาให้ ให้เช็กการใช้งานใน Google AI Studio หรือใส่ `GEMINI_API_KEY_BACKUP` (คีย์จากอีกโปรเจกต์) ระบบจะสลับไปใช้ให้อัตโนมัติ
- ขึ้น `gemini session reset: 1011 ... exceeded your current quota` ตั้งแต่เริ่มสาย อาจเป็นการเตือนผิด: บางคีย์ทูล Google Search ทำให้เซสชัน Live เปิดไม่ขึ้น `callme` จะลองใหม่โดยไม่มี Google Search ให้เอง 1 ครั้ง (ดูบรรทัด `retrying without the google_search tool` ใน `data/callme.log`) สายจะไปต่อได้ แค่ค้นเว็บสดไม่ได้
